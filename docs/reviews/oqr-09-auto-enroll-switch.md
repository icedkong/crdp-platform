# OQR-09：自动入组开关实施记录

日期：2026-11-20。分支：`codex/oqr-09-auto-enroll-switch`。关联 OQ-88、OQ-35、A-FU-016 / 017、E14-T02 / T05。

## 实现

计划新建弹窗和未发布计划的基本信息编辑区增加 Ant Design Vue Switch，标签「自动入组」，选项「开启 / 关闭」。新建默认关闭；详情只读显示服务器真实状态，编辑从当前版本回填。固定辅助文案说明发布后仅影响后续出院登记、不补批既有患者、不改变已有入组。

补齐 `packages/api` 中 PlanView、创建与编辑请求的 autoEnroll 类型；新建与编辑均显式发送布尔值。这同时修复了原页面修改其他基本信息时遗漏开关、被后端缺省 false 意外关闭的问题。保存期间开关禁用，新建 / 编辑提交增加忙碌保护；编辑权限按响应式状态判断，失去权限时基本信息恢复只读。

沿用已有 `followup:plan:edit`、baseVersion 乐观锁与 40900 冲突处理；冲突后重新加载服务器值，不擅自覆盖。已发布版本仍不可直接编辑，需复制成新版本；复制沿用开关，发布后仅后续新登记使用新的配置。没有新增接口 / 权限码 / 功能开关 / 数据库迁移，也未改后端入组规则、租户路由、患者范围或医院 C 器械映射。

后端 PlanService 已有计划变更审计与 fu_plan_log 前后快照（含 autoEnroll），本项沿用；无新增患者敏感字段或明文保存。类型只补已有服务器字段，不新增临床表单字段。
