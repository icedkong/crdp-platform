## 3. 演示中发现的问题与环境限制

1. **（环境限制，非产品缺陷）内嵌浏览器弹层组件不发数据请求**：本次演示所用 ZCode 内嵌浏览器（IAB）中，权限预览抽屉、平台端验链结果弹窗能被打开（open 状态生效、标题与表头渲染正常），但弹层组件挂载后的数据请求不发出（页面内拦截 `fetch`/XHR 证实 0 请求）；审计中心的 AntD RangePicker 也不接受合成 change 事件。同环境内普通页面（列表、表单、向导、登录）全部正常，与 M2 验收记录的内嵌浏览器 rc-motion 弹层动画冻结（m2-acceptance.md §2.3）同族。**同一批接口的 API 调用 32 项断言全过、`M1FoundationRegressionIT` 5/5**，故定性为演示环境限制；产品 / 医院现场演示请在普通浏览器（Chrome / Edge / Safari）复演第 11、13–17 步。
2. **（待复核，不阻塞验收）demoa `nurse.demo` 登录后跳 `/mobile`（MobileBlocker 页）**：新租户 `m1ui` 登录正常进 `/dashboard`；同浏览器同窗口 demoa 租户 `nurse.demo`（种子租户管理员）登录后被导向 `/mobile`「请在电脑或平板上操作」（视口 1280×720 非手机宽度）。医院端源码无 `/mobile` 路由注册，疑与种子菜单 / 登录后跳转记忆有关，本次未定位根因；不影响本任务四条验收链路（demoa 仅为对照试验用），留待后续在普通浏览器复核后再决定是否单开缺陷任务。
