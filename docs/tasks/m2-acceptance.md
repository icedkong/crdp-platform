### 2.3 演示中发现并处理的问题

1. **（已修复）侧栏菜单导航被隐藏详情路由劫持**：点击「我的任务 / 患者档案 / 随访计划」分别落到字面量参数死路由 `/followup/record/:recordId`、`/followup/patient/:id`、`/followup/plan/:planId`，主流程导航全断。根因：Vben `generateAccessible` 给所有带子路由的父路由自动加 `redirect = firstChild.path`（`packages/effects/access/src/accessible.ts`），而这三 个列表菜单的唯一子路由都是隐藏详情路由。修复在仓库自有转换层 `packages/api/src/vben-menu.ts`：隐藏子路由提升到顶层（绝对路径本就全局匹配，`activePath` 保持侧栏高亮），父路由不再带 children 也就不会被加 redirect；`vben-menu.spec.ts` 新增 4 个用例（10/10 绿）。代价：详情页面包屑由「随访 / 随访计划 / 计划详情」退化为单级（见 OQ-89）。
2. **（环境限制，非产品缺陷）内嵌浏览器弹层动画冻结**：本演示所用 ZCode 内嵌浏览器的 AntD `Select` 弹层停在 `transform: scale(0)`（rc-motion 动画不推进），导致登记表单的性别 / 病区 / 出院状态三项下拉无法用该浏览器选择；同一表单的文本输入与 DatePicker 正常，API 全链路正常。UI 交互第 5–11 步需在普通浏览器（Chrome / Edge / Safari）复演，属产品 / 医院现场演示时人工确认的部分。
3. **（待产品确认，OQ-88）`autoEnroll` 无 UI 开关**：计划的「登记即自动入组」（Q35）目前只能 API / 种子配置，计划配置页未提供开关；UI 演示以「批量入组」页替代「入组」一步。
