## 1. 开始之前

### 1.1 系统是什么

临床科研数据一体化平台是一套面向医院的患者随访管理系统。医院（称为「租户」）的随访团队在系统里登记患者、建立基线档案，系统按随访计划自动生成随访任务；随访护士和医生在任务里完成电话或门诊随访录入，上传并归档报告单等资料；系统同时负责提醒通知、统计报表和数据安全（脱敏、审计）。平台运营方使用平台端为各家医院开通账号、管理租户生命周期。每家医院的数据相互独立，本院用户只能看到自己负责范围内的患者。

### 1.2 浏览器要求

- 请使用较新版本的 Chrome、Edge 等现代桌面浏览器（建议 1280×800 及以上分辨率）。
- 平板（768px 宽以上）可正常使用主要业务页面；手机仅支持少数关键页面（见第 7 章），其余页面会提示「请在电脑或平板上操作」。
- 不支持 IE 浏览器。

### 1.3 两个入口地址

| 入口 | 使用者 | 地址（演示环境） | 正式环境 |
| --- | --- | --- | --- |
| 医院端 | 医院医护、院方管理员 | http://127.0.0.1:14173 | 以院方通知的地址为准 |
| 平台端 | 平台运营方 | http://127.0.0.1:14174 | 以平台方通知的地址为准 |

医院端账号不能登录平台端，反之亦然，两套账号互不相通。

### 1.4 账号从哪来

- **医院端账号**：由本院管理员在「系统管理 → 用户管理」中创建（或批量导入），首次登录时系统会强制要求修改密码。账号按角色分配权限和负责病区（C 院还可按科室分配），您能看到的菜单和患者由账号权限决定。
- **平台端账号**：由平台方在「平台账号」中创建，并指定该账号负责哪些租户。
- 演示环境预置了一批虚构账号，见附录 A；口令统一为 `Demo@2026`。演示环境所有数据均为虚构，不含真实患者。

## 2. 通用操作

### 2.1 登录（医院端）

**入口**：浏览器打开医院端地址，进入登录页。

**账号密码登录**：

1. 在「租户编码」框输入本院的编码（演示环境如 `demoa`，输入框内有提示），可勾选记住，下次自动填入。
2. 确认页签停在「账号密码」，输入账号和密码。
3. 点击「登录」。登录成功后显示本院名称，进入「首页」。

**短信验证码登录**：

1. 输入租户编码，切换到「短信验证码」页签。
2. 输入账号，点击「获取验证码」，短信发送到该账号绑定的手机号。
3. 输入收到的验证码，点击「登录」。

**注意事项**：

- 连续输错 3 次后，登录框会出现**图形验证码**，需按图片输入附加码；这是正常防护，不是故障。
- 连续失败 5 次会锁定 30 分钟，页面会提示剩余锁定时间，请等待后再试或联系管理员。
- 「账号不存在」和「密码错误」的提示文案相同（租户、账号或密码不正确），系统不会透露账号是否存在。
- 演示环境不发真实短信：点「获取验证码」后，打开**模拟短信页** http://127.0.0.1:18080/dev/mock-sms 查看验证码（手机号脱敏显示）。

### 2.2 首次登录修改密码

新账号或被重置密码的账号首次登录时，系统会直接进入「修改密码」页，按页面提示输入原密码、设置符合密码策略的新密码后才能使用其他功能。

### 2.3 忘记密码

1. 登录页点击「忘记密码」。
2. 按提示通过短信验证身份。
3. 设置新密码后回到登录页用新密码登录。

若手机号已停用或收不到验证码，请联系本院管理员在「用户管理」中重置密码。

### 2.4 修改密码

**入口**：顶栏右侧头像 → 「个人中心」→ 密码设置。

输入当前密码与新密码保存即可。个人中心还可维护基本信息、查看登录记录、管理在线会话和通知偏好。

### 2.5 退出登录

**入口**：顶栏右侧头像 → 「退出登录」。

注意事项：退出登录会清空本机保存的全部表单草稿（防止他人在本机恢复您的录入内容），请先提交或确认无需保留后再退出。

### 2.6 界面布局速览

| 区域 | 说明 |
| --- | --- |
| 左侧菜单 | 按您的角色权限显示。医院端主菜单：**首页、我的任务、随访**（患者档案 / 随访计划 / 报告单与资料 / 待归档区〔仅 C 院〕/ 统计）、**系统管理**（用户管理、角色管理、科室管理、病区管理、审计中心、机构设置、通知设置、字段字典、报告单设置、对比规则、首页卡片配置） |
| 顶栏铃铛 | 站内信铃铛（未读角标，点开消息可跳转对应任务）；系统公告铃铛（查看平台发布的公告） |
| 顶栏右侧 | 当前用户头像，点开有「个人中心」「退出登录」 |
| 多标签页 | 页面以标签页形式保留；患者详情、随访录入、基线编辑会**打开新标签页**，同一记录重复打开时自动切到已有标签 |
| 面包屑 / 页面标题 | 内容区左上角为当前页面标题 |
| 时间显示 | 全站统一北京时间，日期格式 YYYY-MM-DD |

其他约定：

- 列表中姓名、病案号、电话等敏感信息默认脱敏显示（如「张\*明」），需要完整信息时见 4.6「查看明文」。
- 状态颜色全站统一：蓝色=随访中 / 进行中；绿色=已完成 / 已联系；橙=待处理类提示（待录入、窗口外、未接通）；红=逾期 / 标红 / 校验错误；灰=补录、计划中、已停用等。
- 每页列表默认 20 条，右下角可翻页、跳页。

## 3. 随访护士 / 随访员

### 3.1 我的任务：查看与筛选

**入口**：左侧菜单「我的任务」。

**步骤**：

1. 顶部页签切换范围：「我的待办」（默认）/「本病区」/「全部」，页签上显示任务数。
2. 用状态（全部 / 待随访 / 进行中 / 逾期 / 已完成，以及失访候选）、病区、计划日期、负责人（待认领）筛选，点击「查询」「重置」。
3. 右上角可在「列表」与「看板」之间切换；看板按状态分列展示任务卡片（看板不支持拖拽，状态由业务流转决定）。
4. 列表为空时：有筛选条件点「清除筛选」；确实没有任务且您有计划权限时，页面引导「去新建计划」。

任务状态含义速查：待随访=尚未开始；进行中=已认领或已暂存；逾期=已过窗口未完成（已过窗口仍可补录提交，记为逾期完成）；失访候选=随访员提交待医生确认；已完成=已提交（按时 / 逾期）。

**说明**：列表只显示您权限范围内的任务。C 院列表还会显示当前器械类型、随访时间点、上次随访标红项数。

### 3.2 认领任务

**入口**：我的任务 → 「本病区」或「全部」页签中负责人为「待认领」的行。

**步骤**：点击行内「认领」，任务负责人变为您，状态转为进行中。

**注意**：认领后任务出现在「我的待办」；其他同事将不能再操作该任务。

### 3.3 开始录入并提交（核心流程）

**入口**：我的任务 → 行内「录入」。

**步骤**：

1. 点击「录入」，系统创建录入草稿，并在**新标签页**打开随访表单。
2. 按左侧分组锚点逐组填写（A 院：随访概况、随访结局、临床事件等；C 院：随访概况、症状与检查、电池、起搏阈值与脉宽、感知、阻抗、起搏比例与程控参数、ICD 项目〔仅 ICD / CRT-D 患者〕）。表单顶部会显示患者、随访时间点、计划日期与窗口；C 院还显示当前器械与随访时间点。
3. 随时点击底部「暂存」（或按 Ctrl/⌘+S）保存到服务器；页面顶部状态条会提示「已自动保存 HH:mm」「有改动待同步（每 2 分钟）」等。
4. 填写完成后点击「提交」，在「确认提交」弹窗中确认。

**提交结果**：

- 常规随访：提示「已提交；按计划生成下次任务」，任务变为已完成（按时）。
- 本次结局选择死亡或失访：需再次确认，提交后随访计划终止，不再生成后续任务。随访员提交的失访只是「失访候选」，需医生确认（见 4.5）。

**暂存与自动保存**：

- 系统每 30 秒自动在**本机**存草稿、每 2 分钟（有改动时）同步到**服务器**；暂存后任务转为进行中，刷新或换电脑（服务器草稿）都能继续。
- 断网时改动只存本机，可以继续录入，但**离线不能提交**；恢复网络后自动同步。
- 再次打开表单时若有未提交草稿，会提示「发现未提交的草稿，是否恢复」。

**上一条 / 下一条**：

- 底部「← 上一条」「下一条 →」按当前任务队列顺序切换，适合连续录入。
- 有未保存修改时切换会弹窗询问：「暂存并离开」/「放弃修改」/「取消」。

**版本冲突**（两人同时编辑同一份草稿时）：

- 顶部出现冲突提示条「版本冲突：××× 于 ×× 时间修改了 ×× 字段」，自动保存暂停。
- 可选「保留我的并覆盖」或「载入服务器版本」（自己的改动另存本机副本）。请先处理冲突再提交。

### 3.4 随访表单录入要点

- **必填项**：标签前带红色 \*。漏填点提交时，顶部提示「还有 n 个必填项未填写，已在左侧导航标出」，并自动定位到第一个漏填处。
- **软范围提示**（黄色）：数值超出建议范围（如心室阻抗填 5000）时出现黄色提示；确认无误后可以继续保存，系统会记下确认人。
- **带入上次值**：字段旁灰色小字显示上一次的值；点「历史」可看最近 3 次数值。与上次差异明显时字段标红（红底 + ▲，如「上次 0.7 V（日期），升高 71%」）——这是提醒，不拦截提交，也不会发出通知。
- **对照报告单分屏**：从患者详情报告单页签点「对照录入」进入表单时，右侧分屏显示报告单图片（可缩放、旋转，带水印），边看边录。平板 / 手机上改为全屏切换。
- **手机拍照上传二维码**：表单页关联报告单区域点「手机拍照」，弹出「扫码用手机拍照上传」二维码（15 分钟内有效、一次性使用）；手机扫码后即可拍照上传，提交后自动归档到当前患者（详见 7.2）。
- **同日重复**（仅 C 院）：同一患者同一天已有随访记录时会提示，确认后仍可保存。
- 键盘：Tab 按分组跳转；Enter 不提交；Ctrl/⌘+S 暂存；Ctrl/⌘+Enter 提交。

### 3.5 沟通记录

**入口**：患者详情 → 「沟通记录」页签 → 「记录沟通」。

**步骤**：

1. 选择沟通方式（电话 / 微信 / 面谈 / 其他）和联系结果（已联系 / 未接通 / 号码错误 / 拒访 / 家属代答 / 告知已故）。
2. 可选填约定下次联系时间、情况说明，并可上传录音（MP3 / M4A / WAV）。
3. 点击保存，提示「已记录沟通」。

**注意事项**：

- 结果选「未接通」时，系统**次日自动生成跟进任务**，责任医生同时收到站内信。
- 结果选「告知已故」时，系统按死亡终止该患者的随访计划，请谨慎选择。
- 上传的录音会同时出现在「报告单」页签，显示为一份「通话记录」资料，两处是同一文件，删除任一处两边同时删除（删除前会提示确认）。
- 患者已终止（死亡 / 停止 / 失访）时「记录沟通」按钮置灰。

### 3.6 失访候选与失访确认

- 随访员在随访表单「本次结局」选择「失访」并提交后，患者进入**失访候选**状态，任务列表出现候选标记；随访员本人不能最终确认。
- 由随访医生在我的任务中对失访候选任务点「确认失访」（需填写原因）完成确认（见 4.5）。

### 3.7 临时任务与提醒类任务

- 「+ 临时任务」：为某位患者手工新建一次临时随访（选择患者、计划日期与窗口宽度），不占用年度随访节点。
- 站内提醒类任务（无需填表）：行内点「完成提醒」，确认后即完成。

## 4. 随访医生

### 4.1 患者列表与检索

**入口**：左侧菜单「随访 → 患者档案」。

**基本操作**：

- 关键词框支持「姓名或病案号精确查找」；配合病区、随访状态、下次随访时间筛选，点「查询」「重置」。
- 勾选患者后出现批量条：「批量指定责任医生」「批量入组」「清除勾选」（手机端不提供批量操作）。
- 行内「详情」打开患者档案（新标签页）；「⋮ 更多」里有「转病区」「删除」等（需相应权限）。

**高级检索**：

1. 点击「高级检索」，在弹窗中逐行添加条件：选择指标（字段）、运算符、条件值，行间用「并且 / 或者」连接，可加减条件、组成条件组。
2. 底部有只读的「逻辑表达式预览」，方便核对。
3. 点「保存为个人筛选」后，以后可从「我的筛选」下拉直接调用、更新、重命名或删除（仅本人可见）。

**说明**：A 院列表展示姓名（脱敏）、编号、病区、责任医生、出院日期、下次随访、随访状态、基线 / 随访资料完整度等列；C 院列表展示随访编号、当前器械类型与品牌、植入时长、最近随访日期、下次计划日期、ERI 标记、待录入扫描件数、科室病区等列。

### 4.2 新建患者（登记）

**入口**：患者档案 → 「+ 新建患者」。

**步骤**：A 院填写病案号、姓名、性别、出生日期、病区、入院 / 手术 / 出院日期、出院状态等；C 院填写姓名、性别、出生日期、病历号、科室、病区，并可直接录入第一条植入记录（器械类型 + 电极）。保存后列表出现新患者。

**注意事项**：

- 病案号 / 病历号重复会被拦截；C 院「姓名 + 出生日期」相同会提示可能重复、可继续。
- C 院保存后系统自动生成随访编号（形如 105-2026-001），并按器械类型自动加入对应随访计划。
- 出院状态为「死亡」的患者不会生成随访任务。

### 4.3 患者档案（详情页）

**入口**：患者档案列表 → 行内「详情」（新标签页打开）。

**页签一览**：

| 页签 | 内容 |
| --- | --- |
| 基线资料 | 患者登记信息与基线数据分组只读视图；C 院还包含当前器械摘要、植入记录与电极区块 |
| 随访记录 | 随访时间轴（可切表格）：历次随访节点、计划日期与窗口、完成情况；C 院时间轴上还插入植入 / 更换等器械事件 |
| 报告单 | 报告单双树（按类型 / 按时间）+ 列表 + 右侧带水印预览 |
| 参数趋势（仅 C 院） | 起搏阈值 / 感知 / 阻抗 / 起搏比例 / 电池电压等折线图与历次参数表 |
| 沟通记录 | 联系时间、方式、结果、约定下次联系、录音、操作人 |
| 操作日志 | 该患者的操作留痕（谁在何时查看明文、修改、下载等），只读不可删 |

**基线编辑**：基线资料页签右上「编辑」在新标签页打开分节编辑页；填写时如身高 / 体重，BMI 等派生字段自动计算（标「自动计算」只读）。分节可单独保存，也可「暂存」分次补录。两人同时编辑同一分节时后保存方会遇到版本冲突弹窗，可选「保留我的并覆盖」或「载入服务器版本」。修改字段时会要求填写**修改原因**，留痕在操作日志。

**基线锁定**：确认无误后可「锁定」基线，锁定后只读；解锁需「锁定/解锁基线」权限并填写原因（见 5.2 权限分配）。

### 4.4 历史补录与计划外随访

- **历史补录**：患者详情 → 「随访记录」页签 → 「历史补录」。填写随访日期（不早于当时器械植入日期、不晚于今天）开始录入，不需要任务、不受窗口限制；C 院系统会按日期自动建议随访时间点（如术后 1 个月），建议可改选。记录来源标注「补录（纸质）」。C 院提交成功后可点「继续补录下一次」连续录入（保留患者与器械、清空测量值）。
- **计划外随访**：患者详情头部 → 「计划外随访」。用于临时就诊等计划外的随访记录，随访时间点记为「其他」，不影响后续节点。
- **远程监测**（仅 C 院，需院方开通）：随访记录页签工具栏「远程监测」，填写随访日期（不能晚于今天）后用同一张程控表单人工录入，随访方式自动带入「远程监测」，在时间轴上单独成节点与门诊程控区分。
- **C 院注意**：补录一条记录**不会**自动完成窗口内待办任务。若该患者有待随访 / 逾期任务，请到「我的任务」中直接开始录入并提交，任务即完成。

### 4.5 改派任务与确认失访

- **改派**：我的任务 → 行内「改派」修改单个任务负责人；或勾选多条后点「批量改派」。改派后新负责人收到站内信，原负责人不再可操作。
- **确认失访**：我的任务 → 失访候选任务的行内「确认失访」，填写原因后患者状态转为失访，随访计划终止。

### 4.6 查看明文（显示完整敏感信息）

**入口**：患者详情头部 → 「显示明文」（仅被授予敏感权限的账号可见此按钮）。

**步骤**：

1. 点击「显示明文」，弹出确认框：「确认显示明文？本次查看写入审计日志（查看人、时间、患者、字段），60 秒后自动恢复脱敏。不需要再次输入密码。」
2. 确认后字段临时显示完整信息，按钮变为「隐藏（60 秒后自动脱敏）」。
3. **60 秒后自动恢复脱敏**，也可提前点「隐藏」。

**注意**：每次查看明文都会写入审计日志；没有权限的账号看不到该按钮，请向管理员申请，不要私下借用他人账号。

### 4.7 植入记录与更换 / 取出（仅 C 院）

**入口**：患者详情 → 「基线资料」页签 → 「植入记录」区块（当前器械置顶）。

**操作**：

- **新增植入记录**：一个患者可有多条植入记录（如对侧囊袋），每条下登记 RA / RV / LV 电极，部位按腔室自动过滤；同一时间只有一条「在用」。
- **更换 / 升级 / 电极修正**：点「更换 / 升级」选择类型（更换〔电池耗竭〕/ 升级 / 电极修正 / 其他，「其他」须填说明）。旧器械自动标「已更换」并记结束日期；沿用的电极保留原植入日期、参数趋势保持连续；废弃电极标「废弃留置 / 已拔除」。
- **自动切换计划**：升级为 ICD / CRT-D 后自动转入 ICD 计划并从升级日重新起算；更换电池重新起算节点；取出未再植入则终止计划。未完成的旧任务自动终止并记录原因。
- 器械更换、电极修正等编辑同样需要填写**修改原因**，留痕在操作日志。

### 4.8 程控录入与参数趋势（仅 C 院）

- **程控录入**：从我的任务「录入」进入程控表单，表单自动带入随访编号、随访序号、当前器械、随访时间点与随访医生。字段按器械类型显示：VVI 单腔看不到心房参数与 ICD 治疗字段；CRT-P / CRT-D 才显示 LV 电极字段。
- **下次随访时间**：C 院由医生在表单中填写（作为下次计划日期，并显示窗口预览）；不能早于或等于本次随访日期、不能早于今天。ERI 期随访按「接近 ERI」标记那次随访起算。
- **参数趋势**：患者详情 → 「参数趋势」页签。可按心房 / 心室、阈值 / 感知 / 阻抗 / 比例 / 电池切换查看；标红点高亮（含变化率）；器械更换处画分隔线，沿用电极的阻抗曲线连续。

## 5. 科主任 / 院方管理员（医院端）

### 5.1 用户管理

**入口**：系统管理 → 用户管理。

**常用操作**：

- **新建 / 编辑用户**：点「新建」或行内「编辑」，除基本信息外，按本院维度分配**负责病区**（A 院）或**负责科室 / 病区**（C 院）——这决定该用户能看到哪些患者。
- **导入用户**：点「导入用户」按模板批量导入。
- **重置密码**：行内「重置密码」，新密码经短信发给用户本人；用户首次登录需修改。
- **解锁 / 启用 / 停用**：账号锁定或停用时在行内操作恢复。
- **权限预览**：选中用户可预览其有效权限，方便核对。

**注意**：明文查看、数据导出、删除患者 / 记录等敏感权限**默认不授予**，需按需在角色中单独添加后才可见入口。

### 5.2 角色管理

**入口**：系统管理 → 角色管理 → 行内「编辑」。

角色编辑有四个页签：

1. **菜单按钮**：勾选该角色可用的菜单与按钮（只能在被允许的范围内分配）。
2. **数据范围**：设定该角色可访问的病区 / 科室范围。
3. **字段策略**：设定字段级脱敏策略。
4. **成员**：查看与调整角色成员。

保存后在线成员的下一次请求即按新权限生效。内置角色不可删除。

### 5.3 组织架构与病区

- **科室管理**（系统管理 → 科室管理）：左侧科室树、右侧详情，维护科室层级与人员归属。
- **病区管理**（系统管理 → 病区管理）：维护病区成员、患者数、**默认随访负责人**，可停用病区。
- **转科 / 转病区**：患者档案列表 → 行内「⋮ 更多」→「转病区」（C 院为转科室 / 病区）。转科后任务与扫描资料随患者迁移，保留转科历史；原范围用户不再可见该患者。操作后页面自动返回列表属正常现象。

### 5.4 字段字典与报告单设置

- **字段字典**（系统管理 → 字段字典）：按分类维护字段的显示名、帮助文字、取值范围、是否必填、选项；所有修改留变更记录。表单和检索用到的字段都来自这里。
- **报告单设置**（系统管理 → 报告单设置）：三个页签——**资料类型**（如心脏超声、检验、程控报告单；可增减、停用、排序）、**名称字典**（报告名称绑定指标模板）、**指标模板**（指标项目、代码、单位、参考范围，可按性别区分）。录入报告单时系统据此自动带出指标行并对超范围值标 ↑ / ↓。

### 5.5 随访计划配置

**入口**：随访 → 随访计划。

**步骤**：

1. 「+ 新建计划」创建计划模板：设定起算日期（如出院日期 / 植入日期）、周期与节点。
2. 在计划详情的「节点」页签编辑每个随访节点：偏移、提醒提前量、窗口前 / 窗口后天数、任务类型、责任人类别等；旁边有**计算预览**实时显示计划日期与窗口，方便核对。
3. 「发布」后计划生效，系统按计划为入组患者生成任务。**已发布的计划不能修改**，如需调整请「复制为新版本」后发布新版（患者沿用入组时的版本）。
4. 「患者列表」页签查看在组成员，可单个暂停、恢复、移除（填原因）。

**批量入组**：患者档案勾选多名患者 → 「批量入组」→ 选择已发布计划（与责任医生，可选）→「预检」查看将加入 / 将跳过人数与原因（已在组、已死亡等）→「确认入组」，逐条显示成功与跳过明细。C 院按器械类型自动入组对应计划族，映射可在计划详情的器械映射页签调整。

### 5.6 通知规则

**入口**：系统管理 → 通知设置。

- **事件规则**页签：逐事件设置开关、提前天数、发送时间、渠道（站内 / 短信）、接收人（如窗口预告、即将逾期、已逾期、任务改派、未联系到跟进、每日汇总等）。
- **发送设置**页签：免打扰时段（默认 21:00–次日 08:00 不发短信）、每人每日短信上限等。
- **发送记录**页签：按事件、渠道、结果、日期筛选；失败的可重试。

### 5.7 审计查询与导出审批

**入口**：系统管理 → 审计中心。

- 页签：**操作日志 / 登录日志 / 数据访问日志**（含查看明文、下载等敏感访问）。可按时间、操作人、模块筛选，点行查看详情（前后值对比等）。
- **导出**：点「申请导出审计日志」提交申请；普通用户需等待审批。审批人在「导出审批」中处理「待审批的导出申请」；申请人可在「我的导出」下载。
- 审计数据只可查询与导出，任何人都不能修改或删除。

### 5.8 数据导出（患者数据）

**入口**：患者档案 → 「导出」。

按当前筛选（含高级检索条件）提交导出作业。院方管理员免审批直接生成；普通用户提交后需等待审批，审批通过后在「我的导出」下载文件。下载链接有时效，请及时保存。

### 5.9 首页卡片与统计

- 首页右上「卡片设置」可在角色允许范围内隐藏 / 显示卡片、恢复默认（个人偏好）。
- 系统管理 → **首页卡片配置**：管理员按角色配置卡片目录与顺序，保存后对该角色全员生效。
- 随访 → **统计**：每年随访率 / 节点随访率 / 数据完整度 / 医护负责患者数（C 院另有器械分布、接近 ERI、异常标红记录、补录进度）；可按病区筛选，点击数字可进入对应患者 / 任务列表。

### 5.10 待归档区与纸质资料电子化（仅 C 院，需院方开通）

适合「先扫描、后标注」的纸质资料电子化流程（如病案室集中扫描）。

**上传扫描件**：

1. 左侧菜单「随访 → 待归档区」→「上传扫描件」，一次可选择多个文件（1–50 个）放入待归档区，此时**不需要**选患者。
2. 在清单中点行内「归档」，依次选择患者（检索）→ 类型 → 名称（按类型必填）→ 报告时间（默认当天）→ 位置（至少 1 个），确认后生成正式报告单并退出分拣清单。

**说明**：

- 待归档区按上传人所在科室 / 病区隔离，互相看不到别组的文件。
- 未指定位置的文件在全院「报告单与资料」检索中显示橙色「未指定位置」，可点「指定位置」补齐。
- 报告单的电子化状态（待录入 / 已电子化 / 无需录入）可在报告单与资料页行内「改状态」手工调整；改为「无需录入」必须填写原因并留痕；删除已电子化报告单或移除其随访位置后状态自动回到「待录入」。
- 同一文件重复上传时系统会提示已上传过及所属患者（仅在本人可见范围内提示）。
- 首页 / 统计的「补录进度」= 已电子化 ÷（已电子化 + 待录入），「无需录入」不计入。

### 5.11 历史数据导入（导入向导）

**入口**：患者档案 → 「导入」（需院方开通，且同一时间只允许一个导入作业）。

**步骤**：

1. 下载导入模板，按模板整理历史患者数据（Excel）。
2. 上传文件，系统自动**预检**，生成预检报告（逐行列号、原值、问题原因与级别）；错误行为 0 才能继续，警告行进入人工复核清单。
3. 对重复患者选择处理方式（更新 / 跳过）。
4. 确认导入，下载结果报告核对。
5. 历史批次可在导入历史中查看（行数、状态、操作人），演练批次支持回滚。

**注意**：历史患者的既往窗口不再生成任务、不计入逾期；导入数据须为脱敏 / 虚构样本，**严禁导入未脱敏的真实患者数据**。

## 6. 平台管理员（平台端）

### 6.1 新建租户（开通一家新医院）

**入口**：平台管理 → 租户管理 → 「新建租户」。

**向导步骤**：

1. **基本信息**：填写医院名称（必填）；租户编码可自动生成也可修改。
2. **模块与到期设置**：勾选开通模块、设置到期日；在**配置模板初始化**下拉选择是否复制现有租户的配置包（模板选项显示名称 + 源租户与版本，默认「不使用模板」）——只复制配置，**不含患者数据和账号**。可顺带设置配额（用户数上限、存储上限，默认不限）。
3. **首个租户管理员**：设置该医院第一个管理员账号（可跳过，启用前补设）。
4. **确认**：核对所选模板与设置，提交。

**开通进度页**：自动执行资源开通、初始化、注册、账号初始化、配置模板初始化；未选模板的步骤显示「未选择模板，已跳过」。失败步骤可**重试**或放弃回收。完成后该医院即可登录使用。

**注意**：若新医院要复用某院的配置（如乙院复用甲院），先在「配置模板」页导出源租户配置包，再在向导中应用；重新导入配置模板后需重做本院的功能开关等激活配置。

### 6.2 租户列表与详情

**入口**：平台管理 → 租户管理。

- 列表列：名称、编码、状态、到期日（长期有效显示「长期」）、已开通模块、用户数；支持筛选排序。
- 行内操作：「详情」「进入租户视角」「停用 / 启用」「续期」。
- 状态变更（停用 / 启用 / 续期 / 注销）均需**二次确认并填写原因**，页面会提示影响（在线用户数、进行中任务）。注销走专门的注销流程（书面确认、冷静期、数据迁出与销毁证明）。

**租户详情页签**：基本信息 / 模块（逐个开关） / 授权范围 / 配额（用户数与存储上限、实时用量，80% 预警与满额横幅） / 到期设置 / 管理员 / 操作记录。

### 6.3 平台账号与角色

- **平台账号**（平台管理 → 平台账号）：新建账号（强制绑定手机号）；「重置密码」走敏感操作二次认证；「负责租户」多选指定该账号负责哪些医院。行内有解锁、启用 / 停用。
- **平台角色**（平台管理 → 平台角色）：维护角色与授权；其中「租户视角」页签配置可进入视角、可见范围、租户范围、可代为配置、可代重置密码、可编辑业务数据等能力。

### 6.4 进入租户视角（代查医院数据）

**入口**：租户管理 → 目标租户行内「进入租户视角」。

**步骤**：

1. 在弹窗中选择**查看目的**（排障 / 配置核对 / 培训支持 / 其他）并填写查看说明（必填）。
2. 确认后用视角会话打开该医院端页面。顶部常驻橙色**视角横幅**：显示会话号、剩余时间（无操作 15 分钟自动退出，单次最长 2 小时）和「退出租户视角」按钮；页面带全页水印。
3. 查看完毕点「退出租户视角」。

**视角内规则**：

- 默认**只读**：新增、修改、删除、导出与下载、原件预览一律禁止，页面会提示相应文案。
- 按角色授权可进行受控代操作（如代为配置、代重置密码、代编辑业务数据）：写操作前会弹「代为操作确认」，必须填写原因。
- 视角中的数据按**视角规则**脱敏 / 设盲，医院侧只看到平台支持人员的匿名口径，不会暴露您的真实身份明细。
- 进入、退出和视角内访问全部记入平台审计。

### 6.5 视角规则与双人复核

**入口**：平台管理 → 视角规则。

- 左侧按层级（全局 / 租户 / 模块 / 字段）维护规则，右侧编辑具体内容，可「效果预览」。
- 高敏感规则变更需复核：顶部「待复核的高敏变更」卡片中「同意 / 驳回」；每条规则有「版本记录」抽屉（变更人、前后值、复核人，可回滚）。

### 6.6 系统公告

**入口**：平台管理 → 系统公告。

「发布公告」选择发布范围（全部租户 / 指定租户），发布后医院端顶栏公告铃铛即时可见；可「撤下」已发布公告。

### 6.7 审计中心（平台端）

**入口**：平台管理 → 审计中心。

页签包括：平台操作日志、平台登录日志、视角会话（会话台账与该会话的访问明细）、租户视角记录、视角规则变更、租户控制面日志等。支持按视角会话号钻取、详情前后值对比、同追踪号关联；导出需申请与审批（与医院端同口径）。

## 7. 手机 / 平板使用

### 7.1 哪些页面支持手机

以下页面做了手机适配（手机上以卡片、抽屉、底部操作栏形态呈现）：

| 页面 | 入口 | 手机形态要点 |
| --- | --- | --- |
| 患者列表（患者档案） | 随访 → 患者档案 | 卡片列表 + 底部筛选抽屉，可检索翻页进详情 |
| 患者详情 | 列表点「详情」 | 头部折叠、页签横滑、操作进底部抽屉；C 院的植入记录 / 参数趋势页签同样适配 |
| 随访录入（表单页） | 任务或详情进入 | 单列表单、底部固定栏（上一条 / 下一条、暂存、提交），键盘弹出不遮挡 |
| 我的任务 | 我的任务 | 任务卡片 + 顶部分段筛选，点卡片直接进录入 |
| 报告单上传与查看 | 患者详情 → 报告单 | 卡片列表 + 全屏查看器（可缩放 / 旋转） |
| 基线编辑 | 患者详情 → 基线资料 → 编辑 | 单列表单 + 底部操作栏 |

平板（768px 以上）可在电脑端全部页面使用主要功能。**其余管理页面**（随访计划、导入向导、统计、系统管理各页、平台端全部页面）未做手机适配，手机打开会整页提示「请在电脑或平板上操作」——这是设计如此，不是故障。

### 7.2 手机拍照上传（扫码 → 拍照 → 提交）

适合把纸质报告单 / 随访表拍照后直接归档到某位患者名下，无需登录系统。

**电脑端**：

1. 打开患者详情 → 「报告单」页签（或随访表单页）→ 点「手机拍照」。
2. 弹出「扫码用手机拍照上传」二维码，**15 分钟内有效、一次性使用**；若当前在某个分组 / 分类下，位置会自动预选。

**手机端**：

1. 用手机相机 / 微信扫码，打开上传页（无需安装 App）。页面显示患者（脱敏姓名）。
   - 仅 C 院：要求先登录本院账号（页面提示「请登录本院账号后上传（本院要求）」）。
2. 选择「资料类型」和「位置」（至少 1 个，可多选）。
3. 点「拍照」连续拍摄（或「相册选图」），一份报告单可拍多页；系统自动压缩（不影响清晰度），失败项可「重试」或「移除」。
4. 点「提交（n 张）」，显示「上传成功」即完成；页面提示可在电脑端继续处理，本页可安全关闭。手机端不留存文件。

**注意**：二维码过期时手机页显示「二维码已过期，请在电脑上重新生成」；回到电脑端重新生成即可。上传成功后电脑端刷新即可看到新报告单。

## 8. 常见问题（FAQ）

**Q1：提示「没有权限」或某按钮不见了？**
按钮按权限显示：没有权限的按钮直接隐藏。请联系本院管理员在「角色管理」中为您的角色添加对应权限；若是整个菜单不见，同样由管理员勾选。

**Q2：提示「模块未开通，请联系平台」？**
该功能模块未对本院开通（如 C 院专属功能）。由院方与平台运营方确认后，平台管理员在租户详情「模块」页签开通。

**Q3：页面突然跳回登录页 / 提示登录已失效？**
会话过期（长时间未操作或被管理员强制下线）。重新登录即可；表单草稿存在本机 / 服务器，重新打开表单会提示恢复。

**Q4：提示「系统繁忙，请稍后再试」或数据加载失败？**
先刷新重试；若持续出现，请截图（含提示后括号里的追踪编号）交给本院信息科或平台方排查。

**Q5：短信验证码收不到？**
演示 / 测试环境使用模拟短信，不发到手机：打开模拟短信页 http://127.0.0.1:18080/dev/mock-sms 查看验证码。正式环境请确认账号绑定的手机号正确（可在个人中心查看），仍收不到联系管理员。

**Q6：登录被锁定怎么办？**
同一账号连续失败 5 次锁定 30 分钟，页面显示剩余时间；等待到期，或请管理员解锁。若忘记密码请走「忘记密码」或找管理员重置。

**Q7：忘记租户编码（医院编码）怎么办？**
联系本院管理员查询；演示环境常用 `demoa`（示例医院甲）/ `demob`（示例医院乙）。统一登录页可勾选记住，下次自动带出。

**Q8：导出的文件在哪里下载？**
医院端导出（患者导出、审计导出）提交后在对应页面的「我的导出」里下载；普通用户的申请需先经审批。下载链接 5 分钟有效，过期重新申请。

**Q9：为什么列表里看不到某个患者？**
系统按「负责病区 / 科室」控制数据范围：您只能看到自己负责范围内的患者；不在范围内的患者按「不存在」处理（直接输入网址访问也会提示不存在 / 无权查看）。需要扩大范围请联系管理员调整。

**Q10：为什么有的字段显示为 \*\*\* 或「张\*」？**
敏感信息（姓名、病案号、电话、证件号）默认脱敏。需要完整信息时，由管理员授予「显示明文」权限，然后在患者详情头部点「显示明文」（60 秒自动恢复，全程留审计）。

**Q11：保存时提示「版本冲突」？**
您和别人同时编辑了同一份草稿 / 分节。选择「保留我的并覆盖」或「载入服务器版本」后再操作；多人协作时建议先认领任务避免同时编辑。

**Q12：上传报告单失败或提示格式不支持？**
检查文件大小（单个一般 ≤20MB）与格式（图片 / PDF / 音频等，按院方配置）；提示「病毒扫描服务暂不可用，请稍后重试」时属系统防护，稍后重试即可。手机拍照上传自动压缩，一般不会超限。

**Q13：已发布的随访计划想改节点怎么办？**
已发布计划不可修改（患者沿用入组版本）。在计划列表点「复制为新版本」，修改后发布新版；新入组患者按新版执行。

**Q14：（仅 C 院）补录了记录，为什么任务还是待随访？**
补录不自动完成窗口内任务。请到「我的任务」找到该患者的待随访 / 逾期任务，点「录入」直接填写提交，任务即完成。

**Q15：医院账号能登录平台端吗？**
不能。医院端与平台端账号体系相互独立，用医院账号访问平台端会被拒绝，反之亦然。

### 附录 B：功能开关简介（入口为什么可能不见）

部分功能可被院方 / 平台方开关控制，关闭时**入口直接隐藏**（不是置灰）。您可能遇到的包括：

| 功能 | 开关影响 |
| --- | --- |
| 待归档区（先扫描后归档） | 关闭时「随访」菜单下无「待归档区」入口（A / B 院默认不开） |
| 参数趋势页签 | 关闭时患者详情不显示「参数趋势」页签（仅 C 院场景） |

| 修改已提交记录 | C 院需单独授权；未授权时已提交记录上的「修改」按钮置灰并提示所需权限 |
| 随访序号自动编号 | 关闭时随访序号列为空（仅 C 院场景） |
| 患者批量导入（导入向导） | 关闭时患者列表无「导入」入口 |
| 报告单页签 | 关闭时患者详情不显示「报告单」页签 |
| 医生填写下次随访时间 | 关闭时下次随访时间按计划默认（ERI 期优先） |
| 节点随访率卡片 | 默认不显示，可在首页卡片配置中开启 |
| 异常标红高亮 | 影响录入时与上次的差异标红提示 |

若您认为应当可以使用某功能但入口不存在，请联系本院管理员确认开关状态。

### 附录 C：词汇表

| 术语 | 一句话解释 |
| --- | --- |
| 租户 | 一家接入平台的医院；每家医院数据独立分库 |
| 租户编码 | 登录医院端时填写的医院识别码，如 demoa |

| 窗口 | 某节点允许完成随访的日期区间（计划日前后各若干天）；窗口结束后提交记为逾期完成 / 窗口外 |
| 入组 | 把患者加入某个随访计划，系统随之按计划生成任务 |
| 责任医生 / 负责人 | 对某患者或某条任务负责的医生；任务可改派 |

| 计划外随访 | 不属于任何计划节点的临时随访记录，不影响后续节点 |
| 失访 / 失访候选 | 联系不上患者；随访员提交的为「候选」，需医生确认后正式失访并终止计划 |
| ERI | 起搏器电池接近耗竭的预期更换指征；接近 ERI 的患者进入更密的 ERI 期随访（仅 C 院） |
| 程控 | 对起搏器 / ICD 的参数查询与调整；程控随访记录器械参数（仅 C 院） |
| 植入记录 | 患者器械植入信息（类型、品牌、日期、电极），支持更换 / 升级 / 取出（仅 C 院） |
| 待归档区 | 先扫描上传、暂未指定患者的文件集中区，事后分拣归档（仅 C 院） |

| 脱敏 | 敏感字段默认打码显示（如「张\*明」）；查看明文需权限并留审计 |
| 数据范围 | 账号可见患者的能力边界（按负责病区 / 科室），越界按不存在处理 |
| 暂存 / 草稿 | 未提交的录入内容；本机 30 秒一存、服务器 2 分钟一存，恢复后可继续 |
| 站内信 | 顶栏铃铛内的系统通知（任务提醒、窗口预告、逾期提醒等） |
| 视角（租户视角） | 平台管理员经审批进入某医院端查看数据的只读会话，带横幅水印与审计 |
| 演示模式 | 本地演示环境：数据虚构、短信模拟、加密为本地演示密钥，禁止录入真实患者数据 |
