# ADR 0008：服务器水印预览与隔离转换

- 状态：已采纳（2026-11-19，OQR-07 / OQ-127）
- 关联：E10-T04、E16-T06、A-ATT-005、C-SCAN-018

## 问题

旧预览代理返回原始字节，页面水印无法覆盖绕过页面读取的文件。OQ-127 新定论要求可视预览返回服务器水印副本，原件仅走独立下载授权。

## 决定

JPG / PNG 解码重绘，PDF 逐页栅格化，DOCX 本机 LibreOffice 隔离转换后再栅格化。全部以服务器确定的姓名（账号）、医院、北京时间分钟烧录水印；PDF 重建为图像页，避免原文档可剥离文本、附件和脚本随预览交付。采用 PDFBox 3.0.8；不引入外部转换服务，不修改 framework 接口。

预览内容接口必须携带同一登录会话；256 位随机授权只在 Redis 保存摘要索引，v2 值绑定租户 / 用户 / 会话 / 对象键 / SHA-256 / 大小 / 格式 / 水印 / 到期时间。最长 300 秒，旧授权格式失败关闭。取流前后重载会话、权限版本与范围并检查文件状态；转换期间撤权或文件变更不得交付。图片和文档不再提供匿名原件预览。原件下载保留独立权限和既有签名实现，音频鉴权播放，不承诺不可复制。

前端统一通过 API 客户端取 Blob，viewer 只接收内存地址；DOCX 按服务器 PDF 渲染。到期、会话 / 权限版本变化以及组件关闭时释放地址和显示内容；异步迟到响应不能恢复旧文件。已交付数据不能远程收回。

转换入口是固定绝对路径的本机启动器。生产 Linux 使用 bubblewrap 的新 user / mount / pid / network 等 namespace、只读运行时、隔离临时目录、无网络、无能力和资源上限；不允许直接在应用 JVM 内降级转换。开发 / CI 用无主机挂载的 Docker 子进程验证相同 worker。临时数据只传两份固定文件，结束即清理，不保留预览副本、不跨身份缓存。转换失败、超时、排队满、加密 / 损坏 / 超预算文档统一 50301，绝不回退原件。

## 影响与验收

牺牲可搜索文本和部分高分辨率细节换取水印与预览内容绑定；原件仍可按权限下载。栅格化会增加延迟与 CPU / 内存用量，首期上限为两并发、每次 50 页 / 总计一亿像素、输入输出各 64 MiB、子进程 40 秒。后续容量调整需压测，不能通过取消隔离绕过失败。

本地实际隔离容器已验证 DOCX、PDF、PNG 成功与坏 DOCX 失败；生产 bubblewrap、字体、Office 版式、namespace 策略及容量仍需运维按手册留证。未部署时预览失败关闭，不代表已生产生效。扫描启用、历史补扫与异常文件处置继续由 OQR-08 负责。
