## 1. 目标与验收口径

- 目的：以 E22-T13 资料包为输入配合测评机构完成现场测评（技术核查 + 管理访谈 + 实地验证），
  把机构发现的全部问题整理为**测评问题清单**并落缺陷库，作为 E22-T15 / T16 整改（W44）与
  E22-T17 复测（W45）的工作清单，最终支撑 E22-T18 测评报告备案（W46）。
- 验收拆解（tasks.csv「测评问题清单输出」）：
  - **范围**：现场测评发现的**不符合 + 部分符合项全量**进入清单（只记问题项；符合项不进清单）；
  - **载体**：CSV（列定义即 `onsite-findings-template.csv` 表头，模板行是虚构示例，真实清单只放
    本地文件、不提交仓库——AGENTS §5.5）→ `scripts/mlps_onsite_intake.py` 校验后逐条建为
    GitHub Issues（缺陷库 = icedkong/crdp-platform 的 Issues，OQ-112 ① / OQ-137 ① 暂行）；
  - **可核**：清单条目与 Issue 台账经 `MLPS-ID` 幂等标记一一对应，高风险清零、中风险有处置结论
    以 Issue 全量状态为证（与渗透闭环同构）。
- 时限：高风险项机构通报后 **24 小时内即报即入**（不等报告）；其余在问题清单定稿后
  **2 个工作日内全量入库**。

## 7. 测评问题清单（验收物）：CSV → 缺陷库

流程：机构问题清单（测评记录表 / 报告章节）→ 整理为 CSV（列定义即
`docs/ops/mlps/onsite-findings-template.csv` 表头，模板行是虚构示例，**真实清单只放本地文件，
不提交仓库**——AGENTS §5.5）→ `scripts/mlps_onsite_intake.py` 校验并建 Issue。

```bash
# 校验 + 预览（默认 dry-run，不联网）
python3 scripts/mlps_onsite_intake.py path/to/mlps-findings-w41.csv
# 真正入库（token 取自 git credential fill；幂等：MLPS-ID 已存在则跳过）
python3 scripts/mlps_onsite_intake.py path/to/mlps-findings-w41.csv --apply --ensure-labels
```

- 列（12）：`finding_id`（`MLPS-W{现场测评周次 39~43}-{流水 3 位}`，如 MLPS-W41-003；复测期新发现
  属 E22-T17 口径、不混入本清单）、`title`、`category`（等保十分类）、`control_point`（测评指标 /
  控制点）、`conclusion`（**不符合 / 部分符合**，符合项不进清单）、`risk_level`（高 / 中 / 低）、
  `asset_type`、`description`、`evidence_ref`（测评记录表 / 报告章节编号，证据文件不入仓库）、
  `impact`、`assessor_suggestion`（机构整改建议）、`fix_suggestion`（我方整改方案）；
- 校验：空值、非法分类 / 结论 / 分级 / 资产类型、窗口外周次、重复编号、疑似真实手机号 / 身份证号一律拦截；
- label：`bug` + `mlps` + `E22` + `severity:*`（映射 高 → severity:high、中 → severity:medium、
  低 → severity:low；机构若用四级（加「提示」）改工具 RISK_LEVELS 一处，OQ-137 ②）；
- 整改路由（高 / 中风险在 Issue 正文标注责任任务）：backend → **E22-T15**（测评整改 · 后端 /
  全栈 1）、frontend → **E22-T16**（测评整改 · 全栈 2）、infra → **运维会诊**（云上整改由持账号
  运维执行）、management → **管理会诊**（制度签署 / 记录补齐口径 M-14 / M-16，产品牵头）、
  other → 三方会诊定责；
- 时限：高风险通报后 24 小时内即报即入；其余定稿后 2 个工作日内全量入库；
- 闭环：整改 PR 关联对应 Issue（W44，E22-T15 / T16 验收「整改项全部关闭」）→ 复测（W45，
  E22-T17 验收「复测通过」）结论回写 Issue 并同步 `self-assessment.md` §4 偏差登记 →
  E22-T18 汇总随备案材料提交。
