# 医院 B 预置计划配置与激活 runbook（W37 · E23-T16）

> 任务 E23-T16（产品 · 产品，2 人天，依赖 **E23-T15** B 租户开通；验收：**节点、提醒与窗口按 Q42 配出**）。
> 需求依据：`docs/requirements/hospital-a-spec.md` 第 14 章「随访计划（医院 B 预置）」与「术后第 1 / 3 / 5 天任务」（Q42 窗口与频率、Q43 完整随访记录表单、Q44 出院时建档与补录）、A-FU-016（计划模板三层结构）、A-FU-017（预置计划的 B 侧对应）。
> 按 `AGENTS.md` 第 9 节：生产侧的激活操作（停用 A 预置、发布 B 预置、与医院 B 确认节点参数）由实施 / 租户管理员在场完成，本 runbook 是他们照着走的**配置手册**；仓库交付预置迁移（followup V80）、行级核对（`BPresetPlanSqlTest`，CI 恒跑）与激活路径演练 IT（`BPresetPlanVerifyIT`，门控 CRDP_IT_MYSQL_PORT，demob 作 B 化身走完全链路）。
> 衔接：E23-T15（B 租户开通，配置与 A 一致）→ **E23-T16（本任务）** → E23-T17（B 验收：补录任务与节点随访率）、E23-T19（B 上线切换，复用 `hospital-a-go-live.md` §6 口径）。

## 1. 目标与验收口径

- 医院 B 使用本院预置计划「心脏术后随访（医院 B）」：**以手术日期起算**，节点与提醒、窗口按 Q42 配出——

| 节点 | 计划日期 | 提醒提前量 | 窗口 | 任务与表单 |
|---|---|---|---|---|
| 术后第 1 天 | 手术日期 +1 天 | 0（当天提醒） | 前 0 天、后 1 天 | 随访任务 + 完整随访记录表单（Q43） |
| 术后第 3 天 | 手术日期 +3 天 | 0（当天提醒） | 前 0 天、后 1 天 | 同上 |
| 术后第 5 天 | 手术日期 +5 天 | 0（当天提醒） | 前 0 天、后 1 天 | 同上 |
| 术后 3 个月 | 手术日期 +3 个月 | 2 周 | 前后 14 天 | 电话随访 + 完整随访记录表单 |
| 术后 1 年（第 1 年） | 手术日期 +1 年 | 1 个月 | 前后 1 个月 | 电话随访 + 完整随访记录表单 |
| 第 N 年（N ≥ 2，持续循环） | 手术日期 +N 年 | 1 个月 | 前后 1 个月 | 与 A 一样每年一次、长期不设结束（Q42） |

- 验收判据拆成三件可判定的证据：
  1. **预置行随包且与 Q42 表逐项一致**：followup V80（`B_POSTOP_FU_PLAN` v1）进入所有租户库；行级参数由 `BPresetPlanSqlTest`（CI 恒跑）与 `BPresetPlanVerifyIT`（MySQL 门控）锁定；
  2. **B 侧激活**：A 的「冠心病术后年度随访」在 B 停用、B 预置发布（自动入组生效，出院登记只入 B 预置，Q44 / Q35）；激活路径由 `BPresetPlanVerifyIT` 在 demob 化身走通（状态、变更记录、审计、登记建任务）；
  3. **登记行为**：起算日期 = 手术日期；建档时窗口已结束的术后早期节点补建「补录」任务（BACKFILL，Q44），窗口未结束的当天正常创建；3 个月 / 年度节点按 Q42 窗口开启——IT §Order(3)~(5) 用相对日期锁定（对应规格 §14 虚构示例：手术 2026-03-01、出院 03-08 / 03-05 / 满 1 年三种形态）。

## 2. 载体与状态（为什么不直接随包发布）

- 预置计划属模块配置，随包进**所有**租户库（与 E23-T01 字段字典 V38、E23-T02 A 预置 V61 同口径，`AGENTS.md` §5.7 不写租户分支）。若 V80 直接以 `PUBLISHED + auto_enroll = 1` 落库，医院 A 的出院登记会同时自动入组两套计划（`findAutoEnrollPlans` 取全部已发布计划，followup V50）——因此：
  - V80 落库状态为 **UNPUBLISHED（未发布草稿）** + `auto_enroll = 1`：对医院 A / 其他租户**惰性**（不参与自动入组、不可入组、不进已发布计划候选与 node_rate 缺省计划），医院 B 侧发布后自动入组即生效（OQ-128）；
  - 「不启用 A 的冠心病术后年度随访」是 B 库内的数据动作（停用），同样不进迁移。
- 演示 / IT 环境（local / dev / demo 剖面）每个租户库执行同一份种子（OQ-93 ② 同口径）：demoa 与 demob 都带两套预置（A 预置已发布、B 预置草稿），demob 作 B 化身的激活态由 `BPresetPlanVerifyIT` 自建自清（@BeforeAll / @AfterAll 恢复随包状态，双院配置比对 IT 依赖两库一致）；生产 B 的激活由本手册 §3 一次性完成。

## 3. 激活执行（B 租户管理员 / 实施，开通核对通过后）

前置：E23-T15 的两级核对全部通过（B 租户 TRIAL / ENABLED、配置与 A 一致）。**顺序约束**：配置模板的 `config-template` 步骤会按自然键 upsert 覆盖 `fu_plan` 行（E12-T05），激活必须在模板应用（开通向导）之后进行；此后如需重导 A 配置模板，重导后须重做本节。

| # | 步骤 | 入口（UI / API 等价） | 判据 |
|---|---|---|---|
| 1 | （可选）按需调整 B 预置草稿 | 医院端 → 随访计划 → 「心脏术后随访（医院 B）」编辑（仅未发布可改，A-FU-019） | 保存写 PLAN_UPDATE 变更记录；参数与 Q42 的出入逐项与医院 B 确认留痕 |
| 2 | 停用 A 的预置计划 | 计划列表 → 「冠心病术后年度随访」→ 停用（`POST /api/hospital/followup/plans/{id}/disable`） | 状态 DISABLED（不再允许入组）；写 PLAN_DISABLE 变更记录与审计（A-FU-021） |
| 3 | 发布 B 预置计划 | 「心脏术后随访（医院 B）」→ 发布（`POST /api/hospital/followup/plans/{id}/publish`） | 状态 PUBLISHED、`published_at` 写入；写 PLAN_PUBLISH 变更记录与审计；`auto_enroll` 已为开 → 出院登记自动入组仅此一条 |
| 4 | 抽查登记行为 | 医院端登记一名虚构测试患者（手术日期早于出院 8 天） | 起算日期 = 手术日期；术后第 1 / 3 / 5 天为「补录」任务（Q44）；3 个月 / 1 年节点计划日期与窗口按 §1 表；测试患者随后删除（AGENTS §5.5 不留真实数据） |

- 失败停留：发布被 40901 拒绝 = 计划已被发布过（重入幂等，查变更记录即可）；停用被 40901 拒绝 = A 预置已是停用 / 草稿态（B 初始化异常，回 E23-T15 §5.1 核对）。
- **A 不受影响**：本节全部动作只写 B 租户库；A 库内 B 预置保持未发布草稿（惰性）。

## 4. 回滚与中止

- 激活后发现问题需回退：停用 B 预置（`POST .../plans/{id}/disable`，终态）；A 预置已停用不可恢复（停用是终态，OQ-76），如需回到 A 年度随访 → 计划列表对 A 预置「复制为新版本」再发布（A-FU-019：新版本发布、旧版本自动停用、入组用新版本）。
- 激活做反（误发布 / 误停用）且尚无患者入组：直接按上一条处置即可，无数据残留；已有入组时按 A-FU-020 口径（在组患者沿用入组版本不迁移，迁移首期不做）评估，必要时走 E23-T19 上线前整租户重来（B 尚无正式数据时成本可控）。

## 5. 与首页节点随访率卡片的衔接（A-DASH-012 / 013）

- B 初始化后首页开启「节点随访率」卡片属第 14 章差异清单（E23-T15 runbook §6 行 2，承接任务 E23-T16 / E23-T17）：
  - 卡片目录 `node_rate` 已 `default_visible = 0`（followup V77）：**B 的开启走 `dash_role_layout` 角色布局配置**（租户管理员经 `PUT /dashboard/role-layouts` 逐角色开启，V77 注释口径：不写死租户编码）；
  - 可用性受 `node_follow_rate` 功能开关约束（关 = 40301、前端隐藏）：演示 / IT 由种子 V100 置开；**生产 B 的开关行暂无平台端维护接口**（`GET/PUT /api/platform/tenants/{id}/features` 登记未实现，`docs/api/platform.md`），处置口径见 OQ-128 ④——随 E23-T17 验收定夺（迁移补行或平台端接口接入后配置）；
  - 卡片按 `planId` 筛选、缺省取 id 最小的已发布计划（OQ-109 ③）：B 激活后缺省即 B 预置（A 预置已停用）；节点行标签 = 固定节点用节点名（术后第 1 天 / 术后第 3 天 / 术后第 5 天 / 术后 3 个月）、年度循环节点「第 N 年」。
