**预览代理与水印（E10-T04，已实现）**：预览**经应用代理按流返回、不缓存**（不暴露对象存储直链）——登录态调 `preview-url` 换短时链接，浏览器子资源凭令牌从 `/files/preview/{token}` 取流（OQ-62 ②：审计记在**签发**一次，取流不重复记，音频 range / pdf.js 分页多次请求不刷审计）。水印在前端（`packages/viewer`）：平铺文本「姓名（账号）· 医院名称 · 预览时间（精确到分钟）」，canvas 平铺、旋转 -20°、透明度约 0.15、`pointer-events: none`，**不可关闭**——节点被删 / 样式被改由 MutationObserver 立即重绘并每 2 秒自检兜底；MP3 / M4A / WAV 原生 `<audio controls controlsList="nodownload">` 播放（不转码、播放器内无下载按钮），AMR 与 XLSX 只下载（下载按钮按 `followup:scan:download` 显示，签名下载已随 E10-T05 落地：`download-url` 签发 + `/files/download/{token}` 附件取流）；PDF 用 pdf.js、DOCX 用 docx-preview 页内渲染（懒加载）。PDF 页数不回填 `sys_file.pages`：预览解析在前端完成，后端仍不引 PDF 解析依赖（OQ-61 ④）。**水印口径（G6 / OQ-127）：水印仅页面层——短时预览链接与签名下载返回的是对象存储原始字节（无水印），持有直链者在 5 分钟窗口内绕过页面看到的是原件；防线 = 短链 5 分钟 + 每次签发写审计 + 下载需单独权限且写审计。若上线 / 等保要求水印随文件走，需在预览与下载代理烧录（另立任务，OQ-127）。**

**签名下载（E10-T05，已实现）**：下载是敏感权限（`followup:scan:download`，plt_sensitive_perm；不进授权范围模板、不预授予内置角色，医院要用先由平台管理员在租户授权范围放开）——登录态调 `download-url` 换 **HMAC-SHA256 签名链接**（`{payload}.{sig}`，负载含租户与到期时间，5 分钟内有效、无状态不依赖 Redis），取流口凭签名恢复租户上下文后从对象存储附件返回原字节；**每次签发写一条 `DOWNLOAD` 数据访问审计**（含文件 SHA-256，`fileHash` 扩展字段），取流不重复记（OQ-62 ② 同口径：签名绑定签发人，5 分钟窗口内取流可归因）。签发后文件被软删除的，窗口内链接同样 40400（台账状态优先于签名）。
