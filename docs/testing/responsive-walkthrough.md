### 3.1 顺带确认的非问题（走查中质疑、核实后符合设计）

- **高级检索手机抽屉出现「+ 条件组 / 逻辑表达式预览 / 保存为个人筛选」**：components.md §11.2 的 `mobileCommonOnly` 语义是**字段目录**只留常用字段（实现按 `common` 过滤，实测只剩常用项），构建器能力本身保留——符合设计。
- **患者卡片「下次随访 —」**：API `summary.nextVisit` 恒 null（本机无每日调度刷新缓存），桌面同样为「—」，非响应式缺陷。
- **患者列表 `MenuItem` / 临时任务弹窗 `a-select` 组件解析告警**：存量 dev 告警，不影响渲染与交互，不在本任务范围（已在此登记，供后续清理任务参考）。
