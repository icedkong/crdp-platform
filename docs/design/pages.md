### 0.2 通用页面行为

| 主题 | 规则 |
|---|---|
| 菜单来源 | `GET /api/hospital/menus`（后端按有效权限裁剪，PLT-PERM-005），前端不硬编码菜单；隐藏路由也由后端下发（`hidden=1`） |
| 路由守卫 | 未登录 → `/login`；无菜单权限 → 403 页（`a-result status="403"`「没有访问权限，请联系本院管理员」）；路由 meta `responsive !== true` 且手机 → `MobileBlocker`「请在电脑或平板上操作」 |
| 多标签页 | 保留（桌面 / 平板）；手机不显示；患者详情、随访表单、基线编辑都开新标签页（同一记录重复打开时切到已有标签） |
| 页面骨架 | `div.page`（padding 16）+ 白色主卡片；左上页面标题 18/600；筛选栏 1–2 行；右上操作按钮；表格；右下分页（20 条/页） |
| 错误 | 接口 `code !== 0`：`40100/40101` 跳登录；`40300/40301/40302` 显示无权限并刷新权限码；`50000/50002` 显示 `a-message.error(message)` + traceId；`409` 冲突走各页面专门处理 |
| 时间 | 一律北京时间显示，`YYYY-MM-DD` / `YYYY-MM-DD HH:mm` |
| 数据范围 | 前端不做数据过滤；看不到的数据由后端按“不存在”处理（返回 404 语义的错误码，推断，待确认） |

## 1. 登录与租户识别

| 项 | 内容 |
|---|---|
| 路由 | 医院端 `/login`（`web-hospital`，开发端口 14173）；平台端 `/login`（`web-platform`，14174） |
| 权限 | 公开 |
| 需求 | PLT-AUTH-001、002、003、004、005、006、007、010、011；NFR-SEC-* |
| 组件 | `a-card`、`a-tabs`（账号密码 / 短信验证码）、`a-form`、`a-input-password` |
| 接口 | `POST /api/hospital/auth/login`、`POST /api/hospital/auth/logout`、`GET /api/hospital/auth/me`、`GET /api/hospital/auth/codes`、`GET /api/hospital/menus`（仓库已有）；平台端同名 `/api/platform/...`；租户识别 `GET /api/hospital/auth/tenant?code=`、短信 `POST /api/hospital/auth/sms`、改密 `POST /api/hospital/auth/password`（推断，待确认） |

```text
┌─────────────────────────────── 医院端登录 ───────────────────────────────┐
│                [医院 Logo]  医院 A（示例租户）                             │
│                临床科研数据一体化平台                                       │
│   （统一登录页时先出现）医院编码 [ demoa        ]  ☐ 记住                    │
│   [ 账号密码 | 短信验证码 ]                                                │
│   账号 [               ]                                                   │
│   密码 [               ] 👁                                                │
│   图形验证码（连续失败 3 次后出现，E04-T05 已实现）                         │
│   [            登录（主按钮，撑满）            ]                            │
│   忘记密码                                                                 │
└───────────────────────────────────────────────────────────────────────────┘
```

- 租户识别（PLT-AUTH-004）：通过租户子域名访问时直接显示该院名称与 Logo；统一登录页先输入租户编码（可记住上次输入，只存编码）。本地开发演示租户 `demoa` / `demob`（库 `t_demoa` / `t_demob`）。
- 平台端：账号密码通过后**强制第二因素**（短信），见 PLT-AUTH-003/005。
- 首次登录改密（PLT-AUTH-010）：登录返回“必须改密”时跳 `/password/change`，按密码策略实时提示（PLT-AUTH-006）。
- 失败锁定（PLT-AUTH-007）：显示后端返回的剩余次数 / 锁定时间文案。
- 登录成功：拉 `me`、`codes`、`menus` → 进入 `/dashboard`；**退出登录清空本机全部草稿（IndexedDB）**。
- 响应式：登录页三端都可用（卡片宽 400，手机撑满）。

- 空：卡片内「暂无随访任务 · 去新建计划」（有 `followup:plan:edit` 才显示按钮）。
- 统计卡不用 3D 插画和欢迎渐变卡，用线性图标。
- 响应式：平板两列栅格；手机 `MobileBlocker`（首页不在 5 个响应式页面内；若用户希望手机首页，见 OQ-24）。
