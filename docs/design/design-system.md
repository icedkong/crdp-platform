# 设计规范（Design System）

> **前端必须严格按本文实现。** 依据：UI 线框与界面规范页（2026-10-31 定稿，其中“界面规范（内容区参考竞品）”与“详情页左栏：附件导航”两节优先于旧的可点击线框）、技术方案 V0.2 第 5、6、10、15 章、A / C 规格。凡标“已定”的都是和用户确认过的决定，不要改；本文没写到的，先问人（见 `docs/open-questions.md`），不要自己发挥。
>
> 配套文件：`tokens.ts`（主题变量）、`components.md`（业务组件契约）、`pages.md`（逐页规格）。
>
> 竞品截图只用于参考样式，仓库与文档中不得包含竞品截图或其中任何个人信息。

## 0. 技术基线与 Vben 说明

- 组件库：**Ant Design Vue 4.x**。颜色、尺寸通过 `a-config-provider` 的 `theme` 落地，数值见 `tokens.ts`，并由 Vben preferences 同步主色。
- 外壳：**官方 Vben Admin 5.7.0，仅 Ant Design Vue**（ADR 0002，OQ-01 已关闭）。`apps/web-hospital` 与 `apps/web-platform` 都是基于上游 `web-antd` 的应用。侧栏、顶栏、多标签页保持 Vben 默认样式。不要引入 Element Plus、Naive UI、TDesign、antdv-next，不要恢复已删除的 `@crdp/admin-shell`。
- 本文每条规则仍先写 Ant Design Vue 落地方式，括号里是 Vben 对应物（`Page`、`useVbenModal`、`useVbenForm`、`useVbenVxeGrid`）。样板页见 `reference-pages.md`。
- **不要**在页面里直接写死颜色、字号、间距，一律用 token 或 `components.md` 里的组件。
- 图标：线性图标。菜单用 Iconify（后端若下发 `DashboardOutlined` 这类名字，适配层会转成 `ant-design:dashboard-outlined`）。不用 3D 插画、欢迎渐变卡。
- 字体：沿用 Vben / AntD 默认字体栈；行高 1.5715。

## 2. 页面布局

- 每页一张白色主卡片：左上页面标题（18/600），下接 1–2 行筛选栏，右侧放导入 / 新增等操作，表格紧跟，分页在右下。（AntD：外层 `div.page` padding 16 + `a-card :bordered="false"`；Vben：`Page` 的 title + `extra` 插槽。）
- 首页为多卡片栅格：`a-row :gutter="16"`，卡片间距 16、圆角 8、几乎无阴影。
- 保留多标签页（tabbar）；患者详情顶部为吸顶患者信息条（`PatientHeader`）。
- 菜单与顶栏保持外壳默认样式，只有主色变化。
- 医院端左侧菜单（目标，见 `pages.md` §0）：首页、我的任务、患者管理、随访计划、报告单与资料、统计、系统设置。

## 3. 卡片

- `a-card :bordered="false"`，圆角 8，标题 16/600，**标题前 3px 主色竖条**（用标题伪元素实现，统一封装为 `.crdp-card-title::before`），右上 `extra` 放“编辑”“更多 >”文字链接。
- 统计卡：标签 + 大号数字（24–28/600）+ 右上线性图标；下面加一行 12px 次要色“较昨日 +n / −n”。用 `a-statistic`（Vben：`AnalysisOverview`）。
- 卡片间距 16。

## 4. 表格

| 规则 | 要求 |
|---|---|
| 组件 | `a-table`（Vben：`useVbenVxeGrid`） |
| 密度 | `size="middle"`（约 47px 行高） |
| 表头 | 浅灰底 `#FAFAFA`，无竖线 |
| 首列 | 序号 |
| 对齐 | 文本左对齐，数字右对齐（竞品居中，我们不居中） |
| 分页 | 默认 **20 条/页**；`a-pagination` 开 `show-total`（“共 N 条”）、`show-size-changer`、`show-quick-jumper`；位置右下 |
| 操作列 | `fixed: 'right'`；2–3 个 `a-button type="link" size="small"` + “⋮ 更多”（`a-dropdown`）；删除为红色（`danger`）并用 `a-popconfirm` 二次确认 |
| 状态列 | `a-badge status` 圆点 + 彩色文字（见 §1.2） |
| 敏感列 | 姓名、病案号、电话等默认脱敏显示（`MaskedField` 只读模式，列表中**不提供**逐行显示明文，显示明文只在患者详情头部，见 §10）|
| 空 | 表格内用 `Empty.PRESENTED_IMAGE_SIMPLE` + 下一步文案 |
| 平板 | 保留主要列，其余列点行展开；可横向滚动 |
| 手机 | 只有 5 个响应式页面改卡片，其他页面不适配（§12） |

## 5. 搜索与高级检索

- **行内筛选**：“标签：输入框”，框宽 180–220px；按钮依次：`查询`（主色 + 放大镜图标）、`重置`（刷新图标）、`高级检索`（主色描边 `ghost` + 漏斗图标）。筛选超过 2 行时折叠（“展开 ▾ / 收起 ▴”）。
- **高级检索**：弹窗宽约 900（`a-modal`；Vben：`useVbenModal`）。逐行加条件：指标（只能选字段字典中的字段）、运算符、条件值、逻辑运算符（并且 / 或者）、`+` / `−`；可拖动排序；支持条件组；底部只读“逻辑表达式预览”，如“（病区 = 示例一病区 并且 EF 射血分数 < 40）或者 再住院类型 不为空”。可“保存为个人筛选”。条件行组件全站共用一个（`AdvancedSearch`）。后端只接收结构化条件 JSON，**不允许原始 SQL**（A-PAT-014、A-NFR-009），并自动叠加数据范围。
- **手机**：筛选和高级检索进底部抽屉（`a-drawer placement="bottom"`），高级检索只留常用条件（已定）。

## 6. 表单

### 6.1 弹窗内短表单（新增 / 编辑，字段 ≤ 约 15 个）

- 标签在上（`layout="vertical"`），每行 4 列（`a-row` + `a-col :span="6"`；Vben：`useVbenForm` `layout: 'vertical'` + `wrapperClass: 'grid-cols-4'`）。
- 分组用 14/600 小标题或 `a-divider orientation="left"`，不加卡片。
- 必填红色 `*` 在标签前；输入框撑满栅格列。

### 6.2 整页录入表单（随访表单、基线分类编辑）

- **随访表单 / 基线编辑用整页，在新标签页打开（已定）**，不用抽屉、不用弹窗。
- 标签右对齐、宽 **140px**、紧贴输入框，带冒号（平板 120px，手机标签在上）。只读详情同样右对齐，宽 **120px**。
- 字段按类型定宽，**不随屏幕拉伸**：

| 类型 | 宽度 |
|---|---|
| 数值 | 96px（单位放在框外） |
| 日期 | 160px |
| 单选下拉 | 120–180px（按最长选项） |
| 短文本 | 320px |
| 长文本 | 占满一行 |

- 键盘：Tab 按分组从上到下、组内从左到右；隐藏字段不进 Tab 顺序；**Enter 不提交**；`Ctrl/⌘ + S` 暂存，`Ctrl/⌘ + Enter` 提交；补录提交后可“继续补录下一次”（C-FU-015）。
- 必填错误：红边框 + “必填”文字。标红（与上次对比异常）：红底 + ▲。两者靠形状区分。
- 派生字段：灰色文字 + “自动计算 · 只读” chip，永远不能编辑。
- 报告单带入的字段：主色浅底 + “报告单带入” chip。
- 已提交记录整体只读；有权限才出现“修改”（见 §9 按钮规则例外）。
- 字段、分组、选项、条件显示、必填、校验全部由 **表单模板（字段字典）驱动**，前端不得写死业务字段（`FormRenderer`）。

## 7. 弹窗与抽屉

| 类型 | 宽度 | 用途 |
|---|---|---|
| 简单弹窗 | 520 | 确认、单列短表单 |
| 多列 / 规则编辑弹窗 | 800–960 | 4 列表单、高级检索（约 900）、规则编辑 |
| 右侧抽屉 | 480–720 | **只用于**时间轴上快速查看已提交记录 |
| 底部抽屉 | 100% 宽 | **只用于**手机筛选、手机“操作”菜单、手机附件导航、手机“跳到分组” |

- 弹窗：标题 16/600 + 右上 ×；头部、底部各一条分隔线；底部右对齐 `取消 / 确定`；遮罩约 45% 灰。
- 字段超过约 15 个，或需要对照上次值的，**不用弹窗，改整页**。

## 8. 空状态

- 卡片 / 页面：`a-empty` + 灰色小字，文案必须带下一步，如“暂无随访任务 · 去新建计划”；**有权限才显示按钮**。
- 表格内：`Empty.PRESENTED_IMAGE_SIMPLE`。
- 全局通过 `a-config-provider` 的 `renderEmpty` 统一。
- 规定文案：附件左栏“暂无基线附件 · 上传”“暂无随访附件 · 上传”；筛选无结果“没有符合条件的附件 · 清除筛选”。

## 9. 按钮

- 主按钮实心主色，圆角 6，高 32；次按钮白底灰边；添加、上传、高级检索用主色描边（`ghost`）；图标在文字前。
- **每个区域只有一个主按钮。**
- 整页表单底部栏按钮**右对齐**。
- **权限规则（已定）**：
  - 没有权限 → **隐藏**；
  - 有权限但当前状态不允许 → **置灰**，悬停（触控设备点击）说明原因（`a-tooltip`）；
  - **例外**：已提交记录上的“修改”，没有权限时也置灰显示，提示“需要‘修改已提交记录’权限”，让用户知道可以去申请。
- 功能开关关闭的页签 / 功能 → 直接**隐藏**，不置灰。
- 权限判断统一用 `usePermission().hasPermission(code)` 或 Vben `v-access:code`（见 `components.md`），权限码来自 `GET /api/hospital/auth/codes`。

## 10. 敏感字段脱敏与查看明文（已定）

- 姓名、病案号 / 病历号、电话、证件号默认脱敏显示（服务端脱敏序列化；前端不拿明文）。
- 只有持有对应敏感权限（如 `followup:patient:plain`）的用户才看到“显示明文”入口（在 `PatientHeader`）。
- 点击后**原地确认**，**不需要再次输入密码**。确认文案（照抄）：
  > 确认显示明文？本次查看写入审计日志（查看人、时间、患者、字段），60 秒后自动恢复脱敏。不需要再次输入密码。
- 确认后调用明文接口（每次写审计），显示明文；入口文字变为“隐藏（60 秒后自动脱敏）”；**60 秒后自动恢复脱敏**，也可手动点“隐藏”。
- 明文**只存在组件内存**里：不进 Pinia 持久化、不进本地草稿（IndexedDB）、不进 URL、不进日志、不进浏览器缓存；组件卸载或 60 秒到期立即清除。
- 平台租户视角下按视角规则脱敏 / 设盲（PLT-VIEW-010/011）。

## 11. 报告单预览与水印（已定）

- 预览：图片用 `a-image` 预览（`toolbarRender` 自定义工具栏：下载、旋转、翻转、缩小、放大、关闭），全屏深色遮罩；PDF 用 pdf.js，DOCX 用 docx-preview，XLSX 只能下载；音频用浏览器原生 `<audio controls controlsList="nodownload">`（MP3 为主；AMR 只能下载）。
- **水印**：页面平铺可见水印，内容“**姓名（账号）· 医院名称 · 预览时间（精确到分钟）**”（线框简写为“查看人 · 时间 · 租户”，两者一致，以此为准）；**不可关闭**；用 MutationObserver 监测，水印层被删改时立即重绘（`WatermarkPreview`）。
- 预览走应用代理的**短时有效链接**，不缓存；每次预览写审计（后端负责）。
- 下载：只有 `followup:scan:download` 权限可见；点击后获取 5 分钟有效的签名链接；每次写审计。
- 缩略图显示在报告单的每个位置（分类 / 分组末尾），点开是带水印的查看器。

## 12. 响应式（已定，NFR-RESP-001/002/003）

| 设备 | 宽度 | 布局 |
|---|---|---|
| 桌面 | ≥ 1280px | 左侧菜单 + 顶栏 + 多标签页；表单左侧分组锚点，标签右对齐 140px |
| 平板 | 768–1279px | 菜单收成图标栏；保留多标签页（可横向滚动）；表单单列，标签 120px；分组改为吸顶、可横向滚动的分组条 |
| 手机 | < 768px | 菜单进抽屉（☰）；不显示多标签页，表单顶栏左侧为返回；表单单列、标签在上；分组改为顶部下拉 + 底部抽屉；底部固定操作栏 |

- 断点常量见 `tokens.ts` 的 `breakpoints`（`tablet: 768`、`desktop: 1280`），全站用同一个 `useBreakpoint()`（见 `components.md`）。
- **只有 5 个页面做响应式**：患者列表、患者详情、随访表单、随访工作台 / 我的任务、报告单上传与查看（C 的植入记录、参数趋势随 M5 做）。其他管理页（字段字典、计划配置、导入、统计、系统设置、平台端）平板只保证可用（可横向滚动），手机打开时整页提示“**请在电脑或平板上操作**”。
- 手机输入框占满宽、高 36、字号 16；数值字段弹数字键盘（`inputmode="decimal"`）；键盘弹出时底部操作栏跟随可视区域（`visualViewport`）。
- 悬停提示（标红规则、置灰原因）在触控设备上改为点击显示。
- 拍照上传：`<input type="file" accept="image/*" capture="environment">`，也可从相册选；一份报告单可连拍多页（受每份文件数量上限约束）。上传前前端压缩：**长边 ≤ 2560px、转 JPEG（含 HEIC）、去掉 EXIF（含定位）**；显示进度，弱网失败可重试。部分安卓 / 微信内置浏览器 capture 不一致时退化为系统“拍照或相册”。
- 电脑端“扫码用手机拍照上传”（一次性二维码 15 分钟有效，A-ATT-015）保留，二维码带入当前位置作为预选；`apps/mobile-upload` 保留。

各页面的平板 / 手机细节见 `pages.md`。

## 13. 自动保存（已定，NFR-SAVE-001/002/003）

适用：随访表单、基线分节编辑。已提交或只读的记录**不**自动保存。

| 项 | 规则 |
|---|---|
| 本地草稿 | 每 30 秒 + 每次离开字段（blur）存 IndexedDB；键含租户、用户、记录 ID；**不存明文查看结果**；退出登录时清空本机全部草稿 |
| 服务器草稿 | 每 2 分钟一次，**只在有新改动时**请求：`PUT /api/hospital/followup/records/{id}/draft`；基线 `PUT /api/hospital/followup/baseline/{patientId}/sections/{code}/draft`；请求带 `baseVersion` 与变更字段 |
| 草稿语义 | 任务变“进行中”；不触发提交校验、对比标红通知、下次任务生成、统计写入，不写字段历史 |
| 版本冲突 | 服务器返回 **409**，带更新人、更新时间、两边不同的字段 → **暂停自动保存**，弹窗让用户选：`保留我的并覆盖`（带新版本号重发，后端写审计）或 `载入服务器版本`（自己的改动另存本机副本）；不做字段级自动合并 |
| 离线 | 只存本地，状态显示离线，可继续录入；恢复网络后立即同步一次；**离线时不能提交**（提交按钮置灰，提示原因） |
| 暂存按钮 | 保留，用于立即保存（`Ctrl/⌘ + S`） |
| 状态提示（表单顶部，照抄） | `已自动保存 HH:mm` / `有改动待同步（每 2 分钟）` / `离线 · 改动存在本机草稿` / `版本冲突 · 自动保存已暂停` |
| 未保存提示 | 有改动时关闭标签页、点上一条 / 下一条、切换患者或刷新页面，弹窗三个按钮：`暂存并离开` / `放弃修改` / `取消` |
| 恢复草稿 | 再次打开时如有本地草稿，提示“发现未提交的草稿，是否恢复” |
| 审计 | 自动保存不逐次写审计；覆盖他人版本、提交、修改已提交记录照常写审计 |

## 14. 与上次对比标红（A-FU-027、C-FU-010/011）

- 录入时与“上一次”对比，异常值在**字段内**显示：红底 + ▲；分组标题、左侧锚点 / 分组条上显示该组标红数量。**不弹窗、不发通知、不拦提交。**
- 字段旁只显示上一次的值（12px 次要色）；“历史”弹层（`a-popover`，手机为底部抽屉）显示最近 3 次。悬停显示规则与阈值来源。
- 默认规则（阈值由租户在规则配置页调整，前后端用同一份共享用例）：
  - A（Q41）：EF 下降 ≥ 10 个百分点或 EF < 40；LVDd 增加 ≥ 5mm 或 > 60；LA > 45；返流加重 ≥ 2 级或达到中 / 大量；新发事件；超出提示范围。具体以 `hospital-a-spec.md` 第 5 章“录入时对比提示规则”为准。
  - C（Q02）：起搏阈值升高 > 50%；阻抗波动 > 50%；感知下降 > 50%；ERI 状态或预计电池寿命 ≤ 1 年；脉宽不同时标“仅供参考”。以 `hospital-c-spec.md` 第 5 章为准。
- 计划外随访不作为对比对象；A 第 1 年无上次随访时与基线出院前超声对比。
